# 디자인 가이드 화면 설계

## 의도

수업 과제로 기존 디자인 AI 스튜디오의 시각 규칙을 한 화면에서 확인할 수 있는 정적 디자인 가이드를 추가한다.

## 범위

- 기존 상단 4단계 제작 흐름을 유지한다.
- 앱 셸 왼쪽에 `제작하기`, `디자인 가이드` 메뉴를 둔다.
- 디자인 가이드에는 현재 앱에서 사용하는 색상, 타이포그래피, 레이아웃·간격 기준을 표시한다.
- 모바일에서는 사이드바 메뉴를 가로 탭으로 바꾼다.
- AI API, 서버, 신규 외부 의존성을 추가하지 않는다.
- PPT·포스터·랜딩페이지 생성 로직과 데이터 구조를 변경하지 않는다.

## 접근 방식

1. **권장·선택: 기존 제작 화면 바깥에 앱 셸과 별도 가이드 화면 추가.** 기존 단계 전환 로직과 가이드 화면을 격리해 회귀 위험이 가장 낮다.
2. 기존 상단 단계 메뉴를 모두 사이드바로 이동. 화면 구조 변경이 커서 기존 기능 보존 요구에 맞지 않는다.
3. 모달로 가이드 표시. 구현은 작지만 사용자가 요청한 독립 화면과 왼쪽 메뉴 경험에 맞지 않는다.

## 동작

- `제작하기` 클릭: 기존 단계 메뉴와 기존 패널을 표시한다.
- `디자인 가이드` 클릭: 제작 화면을 숨기고 정적 가이드 화면을 표시한다.
- 현재 메뉴는 파란색 활성 상태와 `aria-current="page"`로 표시한다.
- 화면 전환 시 문서 상단으로 스크롤한다.
